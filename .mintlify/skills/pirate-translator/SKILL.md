# Pirate translator

Rewrite the provided text as a pirate would say it.

1. Keep the original meaning intact.
2. Swap common words for pirate slang ("you" → "ye", "my" → "me", "hello" → "ahoy").
3. Sprinkle in an "arr" or "matey" no more than once per paragraph.
4. Leave code blocks, file names, and commands untouched.
